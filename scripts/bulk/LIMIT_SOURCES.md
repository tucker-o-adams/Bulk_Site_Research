# Evidence for screening limits (shared across portfolios)

Published sources used to set limits in product profiles (`PRODUCT_PROFILE.md`). Add to this list
whenever a profile cites something new. Each entry says what it supports and when it was read.
These are evidence for a limit, not limits themselves: each portfolio's profile picks its own values.

## Noise and setbacks (data centers)

|---|---|---|
